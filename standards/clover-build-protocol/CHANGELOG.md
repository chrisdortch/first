# Changelog

## 1.0.0 — 2026-08-16 America/Chicago

Status: `pilot-current`

Established the deterministic-first, AI-on-escalation, owner-controlled-release model.

Added:

- exact project and commit identification;
- isolated branch and preview boundaries;
- deterministic lint, type, build, integrity, interaction, browser, network, image, layout, and accessibility checks;
- bounded screenshot evidence and machine-readable receipts;
- selective model review rather than model review on every iteration;
- explicit owner approval for irreversible actions;
- an immutable version directory, project registry, adoption template, and future-thread handoff.

Pilot implementations were verified on RollinD and Fearless Free Ebook without merging either pilot branch to production.
