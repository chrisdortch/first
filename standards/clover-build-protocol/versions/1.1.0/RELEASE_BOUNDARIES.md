# Release and authority boundaries 1.1.0

Version 1.1.0 grants no standing authority for:

- merge to a production branch;
- Vercel or OpenAI Sites production deployment or promotion;
- alias, custom-domain, or DNS changes;
- database or object-storage writes;
- schema migrations;
- secret or environment-value changes;
- purchases or recurring-cost increases;
- emails, texts, invitations, posts, or other external messages;
- payment, waiver, reservation, legal-evidence, or customer-record changes.

A separate owner release decision must identify the exact project, commit, saved version or deployment, audience, domain, tests, data effect, known risk, and rollback anchor.

A passing preview remains `not-authorized` and `productionEligible: false`.
