# “Use CloverApps to…” user command contract

## User experience

The owner may begin with one sentence:

```text
Use CloverApps to <desired outcome>.
```

No master-plan paste is required.

## System response

Clover must:

1. resolve the exact project or say that resolution is ambiguous;
2. identify whether the request is a new seed, evolution, diagnosis, status inspection, backup, restore test, preview review, release candidate, OpenAI Site update, or research task;
3. bind the current public canonical plan and target project record;
4. list the live facts that must be refreshed and the connector that can refresh each one;
5. choose the lowest adequate cost lane;
6. state any exact owner-only action;
7. proceed only with the reversible work actually requested;
8. return a receipt and proposed status change supported by evidence.

## Default authority

The phrase authorizes preparation and ordinary reversible preview work within the explicit request. It does not authorize a merge, production deployment, production-data access, domain/DNS change, secret or permission change, purchase, message, agreement, or publication of private information.

## Examples

```text
Use CloverApps to show the latest status of Lakeside Essentials.
Use CloverApps to diagnose the current SongAndStage failure and build a preview-only repair.
Use CloverApps to plant a new seed for a communication app and compare it with Vibe Translator.
Use CloverApps to back up Boat Rentals and prove the restore.
Use CloverApps to prepare RollinD for release, but do not release it.
```
