## What was learned

1. Core should be a governance Kernel, not a universal data warehouse.
2. Raw domain data should remain in sovereign Cells; Core receives minimized, purpose-bound projections.
3. A task-specific Context Compiler is the best bridge between “more data makes Clover smarter” and the need to minimize exposure, token use, confusion, and cross-project contamination.
4. Continuous learning needs a Memory Promotion Ladder. An AI inference starts as a candidate and cannot silently become verified knowledge, workflow policy, or constitutional rule.
5. The immutable Truth Loop and the authority-gated Action Loop should be implemented separately.
6. Owner attention should be budgeted like money and compute. Clover should normally surface one primary item, no more than two secondary items, and only genuine owner decisions.
7. The daily log should be generated from the Event Ledger so it cannot drift into a competing version of history.
8. Plaintext secret reveal should be handled by a strongly authenticated reveal broker that displays directly to the owner without putting the secret in ordinary model context or public logs.
