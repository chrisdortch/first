# AI Handoff — Read Before Portfolio Work

For any future ChatGPT, Codex, or agent thread:

1. Fetch `CLOVER_MASTER_PLAN_POINTER.json`.
2. Read `portfolio/status/current.json`.
3. Read `portfolio/master-plan/CURRENT.md` and the current numbered master plan.
4. Read `portfolio/registry/projects.json`.
5. Read the applicable build and data protocol pointers.
6. Inspect the exact target repository, production branch, deployment, domains, data stores, backup status, and open work.
7. Resolve contradictions through live readback. Do not trust a conversational claim over current repository evidence.
8. Work in one isolated project and version.
9. Update the portfolio ledger when verified work changes status.
10. Recalculate percentages only under `portfolio/PROGRESS_METHODOLOGY.md`.
11. Preserve receipts and rollback anchors.
12. Stop before irreversible action unless the owner gave exact authority for that action.

When asked “what is next?”, answer from `portfolio/NEXT.md`, modified by current verified urgency and owner direction.

When asked “how complete are we?”, report:

- the broad mission score;
- the relevant program-area score;
- the target project score and confidence;
- the evidence date;
- material blockers.

Do not collapse these into one falsely precise number.
