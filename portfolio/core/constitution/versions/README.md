# Clover Constitution Version Drafts

`0.2.md` is a state-neutral draft. It is not ratified, current, merged, deployed, or enforced by a runtime. `../LIFECYCLE_CANDIDATE_V0.2.json` keeps 0.1 as the one current ratified-active version and records 0.2 as a non-current draft.

`../RATIFIER_TRUST_CANDIDATE_V0.2.json` intentionally contains no trusted credential. A future 0.2 ratification requires a separate authenticated owner ceremony bound to the exact draft hash, exact displayed decision, and an authority-neutral policy-validation receipt. Activation verification also requires the full lifecycle and ratifier registries to satisfy their schemas, grant no operational authority, and match canonical hashes supplied by an authenticated trust source. No private key or recovery material belongs in this repository.
